The preview runs locally on Windows, macOS and Linux. Set up the source, connect an AI tool, and open your workspace.

Requires Node.js 22.12+, pnpm and Git. A packaged desktop installer is still in development.

Get started ↗Open local workspace ↗
Run from source
git clone https://github.com/DMRLZZ/DaveCode.git
cd DaveCode
pnpm install
pnpm build
node packages/cli/bin/davecode.js start

The dashboard opens at localhost:4040.

Good questions.

Is DaveCode free?

DaveCode is MIT-licensed software with no DaveCode subscription. Hosted AI providers can still charge you. You can connect local inference instead; performance depends on your machine and model.

Can I use Claude, Codex and Gemini?

DaveCode has API and CLI adapters for these providers. CLI authentication uses the vendor's official login. Provider plans, eligibility and limits still apply. Some CLI adapters are awaiting verification against real installations.

What about Antigravity?

An official Antigravity CLI is available. Its DaveCode adapter is planned; installing that CLI alone does not connect it to the workspace.

Is this ready for everyone?

This is an early preview. The local engine, dashboard and terminal experience exist. Installation still requires some technical setup; desktop packaging and integrated agent sessions are in development.
