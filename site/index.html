Good questions.

Is DaveCode free?

Yes. DaveCode is open source under MIT, with no DaveCode subscription, markup, or credits to buy. You connect your own API keys or official CLI subscriptions.

Can I bring the AI tools I already use?

Yes. Connect Anthropic, OpenAI, Gemini and OpenAI-compatible API keys, or sign in through the official Claude Code, Codex and Gemini CLIs in isolated sandboxes. See the workspace and connection guide.

How does Goal Mode differ from the Autonomous Runner?

Goal Mode decomposes a high-level objective into a DAG of role-based tasks (planner, researcher, writer, implementer, reviewer). Code tasks are handed to the Autonomous Runner, which works on an isolated git branch and runs lint, typecheck and test gates before merging.

Where does my work live?

Everything stays on your machine: SQLite WAL state, AES-256-GCM encrypted keyring, and `.davecode/` project brain files. Only the provider you route to receives your prompt.
